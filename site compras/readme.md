Requisitos do Sistema
1. Requisitos Funcionais
Os requisitos funcionais descrevem o que o sistema deve fazer.
RF01 — Exibição dos filmes
O sistema deve exibir uma lista de filmes disponíveis para compra, mostrando informações como título, gênero, ano, diretor, duração, avaliação e preço.
RF02 — Pesquisa de filmes
O sistema deve permitir que o usuário pesquise filmes pelo nome ou pelo diretor.
RF03 — Filtro por gênero
O sistema deve permitir filtrar os filmes por gênero, como Romance, Ação, Terror, Comédia, Drama e outros.
RF04 — Adicionar ao carrinho
O usuário deve poder adicionar filmes ao carrinho de compras.
RF05 — Alterar quantidade
O usuário deve poder aumentar ou diminuir a quantidade de um filme no carrinho.
RF06 — Remover filme
O usuário deve poder remover filmes do carrinho.
RF07 — Cálculo do total
O sistema deve calcular automaticamente o valor total dos filmes adicionados ao carrinho.
RF08 — Finalizar compra
O sistema deve permitir que o usuário finalize uma compra e gerar um código de pedido.
RF09 — Exibição do pagamento
Após finalizar a compra, o sistema deve apresentar uma tela de confirmação com um QR Code ilustrativo.
RF10 — Exibição da avaliação IMDb:
O sistema deve exibir a nota de avaliação dos filmes, baseada nas informações do IMDb, para ajudar o usuário a conhecer a avaliação de cada título. 

2. Requisitos Não Funcionais
Os requisitos não funcionais descrevem como o sistema deve funcionar, incluindo características de qualidade e desempenho.
RNF01 — Usabilidade
O sistema deve possuir uma interface simples e fácil de utilizar.
RNF02 — Responsividade
O site deve se adaptar a diferentes tamanhos de tela, como computadores, tablets e celulares.
RNF03 — Desempenho
O sistema deve carregar as informações dos filmes e responder às ações do usuário rapidamente.
RNF04 — Organização
O código do sistema deve ser organizado, utilizando HTML, CSS e JavaScript de forma separada e estruturada.
RNF05 — Compatibilidade
O site deve funcionar corretamente nos principais navegadores, como Google Chrome, Microsoft Edge e Mozilla Firefox.
RNF06 — Visual
A interface deve apresentar um design agradável, com informações organizadas e elementos visuais que facilitem a navegação.
RNF07 — Segurança
O sistema não deve armazenar dados pessoais ou informações reais de pagamento do usuário.

3. Tecnologias utilizadas
HTML5: estrutura das páginas.
CSS3: estilização e aparência do site.
JavaScript: funcionalidades, filtros, pesquisa e carrinho de compras.
4. Objetivo do sistema
O sistema tem como objetivo criar uma loja virtual de filmes, permitindo que o usuário navegue pelo catálogo, pesquise e filtre filmes, adicione produtos ao carrinho e simule a finalização de uma compra.
